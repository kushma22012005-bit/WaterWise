METRIC GUIDE

Understanding the Results

01

Mean Absolute Error (MAE)

MAE measures the average absolute difference between actual consumption and predicted consumption. A lower MAE generally means predictions are closer to the actual values.

02

Root Mean Squared Error (RMSE)

RMSE measures prediction errors while giving greater weight to larger errors. It uses the same unit as the consumption target.

03

R² Score

R² indicates how much variation in the target is explained by the model relative to a mean-based baseline. A value closer to 1 can indicate a better fit; a negative value is also possible.

Important: No performance values are estimated or manually invented on this page. The displayed metrics should come from the actual backend evaluation results.
EVALUATION PROCESS

How the Model Is Evaluated

WaterWise uses a Random Forest Regression model, as described in the existing project page. Evaluation should use the chronological test data kept separate from the training data, where that is how the model is implemented.

The actual preprocessing, training and test-splitting logic must remain consistent with the project's backend. The evaluation results help assess model performance, but do not guarantee future predictions will always be accurate.
