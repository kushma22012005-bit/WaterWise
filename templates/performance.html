Understanding the Results

MAE: Shows the average absolute difference between actual and predicted consumption.

RMSE: Measures prediction error and gives greater weight to larger errors.

R² Score: Indicates how well the model explains variation in the test data. A value closer to 1 generally indicates a better fit.

MAE and RMSE use the same units as the consumption target. The R² score can be negative when the model performs worse than a simple mean-based prediction.

Evaluation Method

WaterWise uses a Random Forest Regression model. Its performance is evaluated on a chronological test set that is kept separate from the training data.

The metrics displayed above should come from the actual evaluation results produced by the backend, not manually entered or estimated values.
